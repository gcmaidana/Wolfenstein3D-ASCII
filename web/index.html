About this demo

This demo includes one episode: Escape from Wolfenstein. Its maps, graphics, and audio load automatically.

Save games last for this browser session only. Reloading resets them. Desktop saves persist on disk.

Menus always use original graphics. F6 cycles gameplay display modes; F7 changes detail. Click the canvas to restore keyboard focus.
